  des1, cell_probs = probs1, chance = 1/3,
  subj_prob_range = c(0.45, 0.84), item_prob_range = c(0.46, 0.85),

  power_min = 0.80, ci_width = 12.0, prob_se_method = "joint_delta", engine = "bayes_laplace"
)
res1 <- optimize_sample_size(
  spec1, n_subj_range = c(24, 80), n_item_range = c(16, 48),
  prefer = "balanced", method = "grid", nsim_final = 180,
  workers = 2, seed = 810101,
  control = optimize_control(nsim_init = 60L, nsim_topup = 80L)

Random-Item vs. Fixed-Item-Bank Rasch Calibration

Key Methodological Takeaway

1. Generalizing to new items (plan_rasch_precision) requires sufficient item count (Nitem ≥ 24) to estimate the population item SD (σitem); adding examinees alone cannot rescue a 16-item test (plateaus at 48.3%).

2. Calibrating a fixed item bank (plan_rasch_fixed_bank) separates bank-wide average accuracy from anchor-level accuracy: while Random-Item EB reaches 100% attainment on bank RMSE ≤ 0.45 at N = 80, unpenalized Fixed-Item MML passes worst-item |err| ≤ 0.60 earlier (N = 180, 90.0% PASS) because EB shrinks ±3.0 logit anchors toward zero.
